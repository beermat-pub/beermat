# Branding

The Beermat mark: a round beer mat with the definition sign `:=`.

| File | Use |
|---|---|
| `logo.svg` | The mark, 48 px and up (has the dashed inner ring) |
| `logo-small.svg` | 32 px and below: no ring, thicker sign |
| `icon-32.png`, `apple-touch-icon.png` (180), `icon-512.png` | Raster icons for the website and app |

## Colours

| Name | Hex | Use |
|---|---|---|
| Deep amber | `#c27d18` | The mat |
| White | `#ffffff` | The sign (3.4 : 1 on deep amber) |
| Amber text | `#8f5810` | Links and headings on cream (5.7 : 1) |
| Amber text, dark mode | `#e0a040` | Links and headings on dark (7 : 1) |
| Cream | `#f6efe3` / `#fffaf1` | Backgrounds |
| Ink | `#2b2118` | Body text |
| Dark | `#1c1612` | Dark-mode background |

Wordmark: "beermat" in lower case, [Outfit](https://fonts.google.com/specimen/Outfit) Bold, letter-spacing −0.02em.

## Names

Decided by Dan on 2026-10-28:

| Written | For | Where |
|---|---|---|
| **Beermat** | the app, in text | window titles, menus, the installer, the Microsoft Store listing, docs, sentences ("Beermat imports `.xmcd` files") |
| **beermat** | the wordmark (the logo's lettering) and the command | the logo, the About box's title, `beermat eval` |
| **beermat.pub** | the website, and the publisher | links, the footer, "by beermat.pub" (the Store's publisher name), email addresses |

So the Store reads "Beermat, by beermat.pub". Keep the capital in text, even at the start of a lower-case list; only the drawn wordmark, the command and the domain are lower case.
